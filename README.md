# Radosław (Radek) Cichy

Senior Python backend and platform engineer from Toruń, Poland. Fourteen years of commercial Python, the last eleven in fully remote, international product teams.

I build backend systems end to end: Django and DRF services, PostgreSQL data models, asynchronous processing with Celery, SQS and Kafka, and the AWS infrastructure they run on (Kubernetes, Terraform, Argo CD, OpenTelemetry). Most of my side work now goes into making AI coding agents trustworthy enough for production code.

## Projects

Claude plans and implements, a model from a different family reviews every plan and diff, and hooks rather than prompts keep the rules: the agent cannot stage or commit, every blocking finding gets an answer, and real disagreements go to the human.
- **autoduo** (coming soon): duo driven by Jira and GitLab events. Tickets become merge requests, and review threads get draft replies for a human to approve.
